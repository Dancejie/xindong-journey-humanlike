## 结论

- 32 张人物卡覆盖 16 种 MBTI；每种均为一位男性与一位女性。
- 16/16 组同型双角色均通过差异门禁。
- 32/32 张卡具有独立的 `distinctiveVoiceGate`。
- 近似换皮门禁覆盖全部 496 组两两组合，不只检查完全相同文本。
- 六位欧洲背景角色均为项目原创成年人；职业与生活背景来自欧洲大陆的真实公共场景，但不把国籍当作性格捷径。

## 同型双角色硬门槛

构建器会拒绝同一 MBTI 的两张卡在下列任一核心字段完全相同：

1. `cognitiveStyle.inputFilter`：第一注意对象；
2. `cognitiveStyle.repairMove`：犯错或越界后的修复动作；
3. `interactionStrategies`：面对四类对象时的关系策略；
4. `memoryPolicy.remember`：优先记住的事实；
5. `reactionMatrix.*.speechMove`：支持、追问、挑战、越界时的具体说话动作。

本轮实测 16 组上述五项全部不同。公共边界原则可以一致，但每个人必须通过自己的职业物件、判断顺序和修复动作来表达。

构建器还把职业、tagline、认知顺序、声音、互动策略、记忆偏好与四类反应合并成角色核心签名，同时计算字符序列相似度与三字片段 Jaccard。门槛为：同 MBTI 不得达到 `0.38 / 0.13`，跨 MBTI 不得达到 `0.50 / 0.20`。当前最高同型值为陈叙/乔岚 `0.262 / 0.088`；当前最高跨型序列值为陈叙/Mateo `0.262`，最高跨型 Jaccard 为林屿/江晚 `0.084`，均保留明显安全距离。

作者层 reaction matrix 仍共享“支持 / 追问 / 挑战 / 越界”四个安全轴，但运行时投影会删去“先落到……再从……”“只回答当前能确认的一层”“先停止越界动作”等统一骨架，只把本人的注意对象、价值、兴趣、边界、修复动作、sentence shape 与检索 few-shot 交给 DeepSeek/Dots。这样保留统一安全合同，同时避免 32 人说成同一种 Agent 腔。
